# LW Command Post

Personal Last War: Survival tools (time calculator, power log, help optimizer).

## Host on GitHub Pages

1. Create a new public repository (e.g. `lw-command-post`).
2. Upload these files to the root:
   - `lastwar-ops.html`
   - `manifest.json`
   - `sw.js`
   - `icons/` folder (with the three PNGs)
3. Optionally rename `lastwar-ops.html` → `index.html` so the root URL opens the app directly.
4. In the repo: Settings → Pages → Deploy from branch → main / root → Save.
5. Share the `https://username.github.io/lw-command-post/` link.

## Add to Home Screen

- **iPhone (Safari):** Share → Add to Home Screen
- **Android (Chrome):** Menu → Add to Home Screen / Install app

Data stays on each device via localStorage. Use Export/Import under Buffs to move data between devices.
